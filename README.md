# devepatch

自分が作っているアプリを一覧で管理し、アプリごとのタスクを todo リストのように記録するスマホアプリ（PWA）です。

公開ページ：https://81goattamer.github.io/devepatch/

- **ライブラリ**：管理するアプリをアイコンで並べる。アイコン（ライト／ダーク）・説明文・目的・URL を登録できる。長押しで並べ替え。
- **タスク**：アプリごとのタスクを追加・完了する。1日は午前4時で変わり、完了した日が記録される。
- **設定**：言語（日本語／English）、テーマ、JSON でのバックアップと復元。

データはブラウザ（スマホ）の中だけに保存されます。iPhone ではホーム画面に追加して使ってください。

## 開発

ビルドは不要です。

```
npm start   # http://127.0.0.1:8081 で開く
npm test    # 計算のテスト
python tools/make-icons.py   # アプリアイコンを作り直す（Pillow が必要）
```

ファイルを変えて公開するときは、`version.js` の版を上げてください（更新の知らせとキャッシュの切り替えに使います）。
